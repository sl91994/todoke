# todoke

> A small CLI for managing coordinated vulnerability disclosures — timelines, templates, and submission-ready reports.

**todoke** (届け, _"submit / report"_) keeps a vulnerability from discovery to public disclosure organized in one place: a timeline of what happened when, and one command to render the report in the format each destination wants (GitHub Security Advisory, IPA/JPCERT, etc...).

> ⚠️ **Early stage (v0.1, WIP).** The data model and CLI are still moving. Expect breaking changes.
